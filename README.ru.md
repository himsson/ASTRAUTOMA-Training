# ASTRAUTOMA Training

*[English version](README.md)*

Обучающая часть [ASTRAUTOMA](https://github.com/himsson/ASTRAUTOMA). Здесь делаются веса, которые
грузит приложение: тренажёры, цикл PPO, экзамены и стенд замеров.

Чтобы летать, это не нужно — скачайте веса из основного репозитория, и всё. Это нужно, если
хотите обучить свои, проверить, откуда взялись числа в таблице бенчмарков, или просто почитать,
как оно устроено.

Игра не требуется. Четыре сети из пяти учатся целиком в тренажёрах, живая KSP нужна только для
финального дообучения.

## Установка

```
pip install -r requirements.txt
```

Python 3.10+ и PyTorch. Видеокарта не используется: сети такого размера процессор считает быстрее
— это замер, он лежит в пульте на экране CPU+GPU.

## Пульт

`LAUNCH_KIA.bat` или `python kia_control.py`.

```
  0  эволюция        вся программа в симуляторах, без игры
  1  kRPC
  2  автообучение    бесконечный цикл с полётами
  3  настройки
  4  логи
  5  сброс
  6  память
  7  нейросеть
  8  манифест
  9  выход
```

Пункт **7** — сети: пять ступеней пилота, лестницы конструктора и математика, навигатор, экзамены,
откат весов. Пункт **0** проходит всю программу без человека и без игры.

## Что обучается

| Сеть | Где | Что решает |
|---|---|---|
| Пилот | `sim_env*.py` | дроссель, тангаж, рыскание, крен, отделение |
| Конструктор | `builder_env.py` | какие детали ставить на ракету |
| Математик | `math_env.py` | арифметику манёвров |
| Навигатор | `nav_env.py` | маршрут, окно, гравитационный манёвр |

Пилот проходит пять ступеней, каждая стартует с весов предыдущей:

1. **Тренажёр** — мир настоящий, управление идеальное: команда исполняется мгновенно и точно.
2. **Тренажёр+** — всё, что стоит между решением и ракетой: задержка kRPC 100 мс, блокировка
   стейджинга, ветер, раскрутка двигателя, расход заряда, штраф за полёт боком.
3. **Тренажёр++** — трёхмерная баллистика, вращение планеты и атмосферы, высотные таблицы
   давления и температуры из самой игры, сопротивление по числу Маха с трансзвуковым горбом,
   ползущий центр масс.
4. **Тренажёр+++** — рули задают момент, а не угол, ровно как в игре с выключенным SAS.
5. **Аварии** — тот же мир, но техника ломается посреди полёта: двигатель гаснет или теряет тягу,
   ступень не отделяется, умирает генератор, течёт бак, заклинивает привод рулей. В половине
   полётов на борту экипаж, и он дороже любого спасённого железа.

Ступень сдаётся по экзамену: средняя награда за окно и число чистых орбит. Если политика
разваливается, конвейер откатывается к снимку прошлой ступени и продолжает с вдвое меньшей
скоростью обучения. Хроника — `kia_evolution_manifest.txt`.

## Длинный прогон

```
python kia_neural.py evolve       # вся программа, без человека и без игры
python kia_neural.py stage 5      # одна ступень
python kia_navigator.py           # навигатор, 10 процессов на CPU
```

Ctrl+C останавливает: веса пишутся каждые 30 секунд, ступень продолжится с того же места.

## Бенчмарки

```
python tools/benchmark.py               # все версии из библиотеки весов
python tools/benchmark.py --quick       # малые выборки, проверить сам стенд
python tools/benchmark.py --table       # перерисовать таблицу из data/benchmark.json
```

Один и тот же экзамен для каждой версии весов: seed'ы зафиксированы, шум политики выключен,
нормализатор не обновляется — числа воспроизводятся. Проектировщик меряется скриптом
`tools/bench_designer.py` из основного репозитория: он гоняет настоящий проектировщик, а не копию.

## Выгрузка весов в приложение

```
python tools/export_weights.py --label "мои веса"
```

Раскладывает обученные файлы по папкам модулей, которые импортирует приложение
(**Веса / Знания → I**).
