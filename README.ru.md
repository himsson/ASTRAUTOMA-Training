# ASTRAUTOMA Training

*[English version](README.md)*

Здесь учится [ASTRAUTOMA](https://github.com/himsson/ASTRAUTOMA). Если вы просто хотите летать —
вам сюда не нужно: скачайте готовые веса из основного репозитория, и всё. Эта папка нужна, если
хочется обучить своё, проверить цифры из таблицы бенчмарков или просто посмотреть, как оно
устроено внутри.

Игра не нужна. Четыре сети из пяти не видят KSP вообще — они живут в тренажёрах, а тренажёры
написаны так, чтобы врать поменьше. Живая игра понадобится только в самом конце, для финального
дообучения.

## С чего начать

```
pip install -r requirements.txt
py -3 train_all.py
```

Всё. Дальше можно идти спать: по очереди обучатся математик, конструктор, навигатор и пилот,
веса будут писаться на диск по ходу, а журнал — в `data/train_all.json`. Ctrl+C останавливает;
следующий запуск продолжит с того места, где вы прервали, а не начнёт заново.

Если хочется не всё сразу:

```
py -3 train_all.py --status        что уже пройдено
py -3 train_all.py --only pilot    только пилот
py -3 train_all.py --from navigator  навигатор и дальше
```

Видеокарта не используется, и это не упущение: сети здесь маленькие, и процессор считает их
быстрее — замер лежит в пульте, экран CPU+GPU.

## Пульт

Если хочется управлять руками, а не одной кнопкой, есть пульт: `LAUNCH_KIA.bat` или
`python kia_control.py`. Пункт **7** — все сети по отдельности, ступени, экзамены, откат весов.
Пункт **0** — то же, что `train_all.py`, но только для пилота.

## Кто чему учится

Сетей четыре, и у каждой своя работа.

**Математик** считает арифметику манёвров — Циолковского, vis-viva, Гомана, фазовые углы.
Учится быстро и в приложении, честно говоря, не используется: у этих задач есть точные формулы,
и программа считает ими. Сеть здесь скорее проверка, что мир тренажёра не врёт.

**Конструктор** выбирает, какие детали поставить на ракету. Ему тяжелее всех: награда приходит
только в конце сборки, и за «поставил бак без двигателя» градиент такой же, как за «забыл
парашют».

**Навигатор** решает, куда и когда лететь: маршрут, окно, стоит ли ловить гравитационный манёвр.
Сначала повторяет за точным планировщиком, потом доучивается сам. Вот он в приложении работает
по-настоящему.

**Пилот** ведёт ракету. Проходит пять ступеней, и каждая начинается с весов предыдущей:

1. **Тренажёр.** Мир уже настоящий — атмосфера, тяга, масса, — но управление идеальное: команда
   исполняется мгновенно и точно.
2. **Тренажёр+.** Появляется всё, что стоит между решением и ракетой: сто миллисекунд задержки
   kRPC, блокировка стейджинга на две секунды, ветер, раскрутка двигателя, расход заряда на рули
   и штраф за полёт боком. Именно здесь обычно разваливается политика, выученная в идеальном
   мире.
3. **Тренажёр++.** Физика перестаёт быть игрушечной: трёхмерная баллистика, планета и атмосфера
   вращаются, давление и температура берутся из высотных таблиц самой игры, сопротивление
   считается по числу Маха с трансзвуковым горбом, центр масс ползёт по мере выработки топлива.
4. **Тренажёр+++.** Рули задают момент, а не угол — ровно как в KSP с выключенным SAS. Угол
   становится двойным интегралом от команды, и ошибки начинают копиться.
5. **Аварии.** Тот же мир, но техника ломается посреди полёта: двигатель гаснет или теряет тягу,
   ступень не отделяется, умирает генератор, течёт бак, заклинивает привод. В половине полётов
   на борту экипаж, и он дороже любого спасённого железа — за живых +60, за погибших −120, тогда
   как беспилотник считается в тоннах.

Ступень сдаётся по экзамену: средняя награда за окно и число чистых орбит. Если политика
поехала — конвейер сам откатывается к снимку предыдущей ступени и продолжает с вдвое меньшей
скоростью обучения. Что когда переводилось и откатывалось, видно в `kia_evolution_manifest.txt`.

## Замеры

```
py -3 tools/benchmark.py            все версии весов из библиотеки
py -3 tools/benchmark.py --quick    малые выборки, проверить сам стенд
py -3 tools/benchmark.py --table    перерисовать таблицу из json
```

Один и тот же экзамен для каждой версии: seed'ы зафиксированы, шум политики выключен,
нормализатор не трогается. Числа воспроизводятся, и их можно сравнивать между версиями — ради
этого всё и затевалось. Проектировщик меряется скриптом из основного репозитория, потому что там
живёт настоящий проектировщик, а копия врала бы.

## Как отдать веса приложению

```
py -3 tools/export_weights.py --label "2.0"
```

Раскладывает обученное по папкам модулей, которые приложение импортирует через
**Веса / Знания → I**.
